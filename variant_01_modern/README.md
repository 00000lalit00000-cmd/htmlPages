# Variant 01 — Modern (Corporate · Navy-led)
**Folder:** `ux/pages/variant_01_modern/`

Colors derived from the brand logo. Arrangement emphasizes **deep navy + gold** with magenta as accent.

## Logo-derived palette
- Primary: `#204060` (navy) · Secondary: `#802060` (magenta) · Accent: `#F0C020` (gold) · Cyan: `#00B0E0`
- Ink: `#16283B` · Muted: `#5B6472` · BG: `#FAFBFC`

## Component design language (variant 01)
| Component | Design language |
|---|---|
| Navbar | Sticky blur, top utility bar (phone/WhatsApp), pill nav, magenta "Get a Quote" pill |
| Hero | Split — left text / right navy gradient card with floating stat badges |
| Services | 4-col icon-tile cards, hover lift + shadow, gold tooltips |
| Stats / testimonial | Numbered navy stat tiles + white quote cards |
| Work / portfolio | Gradient thumbnail cards with magenta tag chips |
| Quote form | Floating-label contiguous fields, 2-col, filled primary submit |
| Footer | Dark navy 4-column footer with newsletter input |

**Open `components.html` to see every component of this variant on one page.**
Navigation is plain `href` links between the HTML files, so every button and menu item navigates.
`../assets/site.js` drives the mobile menu, current-page highlighting and the demo form submit.

## Vibe
Professional, trustworthy, B2B — strong for local SEO and quick scanning.
