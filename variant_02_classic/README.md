# Variant 02 — Classic (Heritage · Magenta-led)
**Folder:** `ux/pages/variant_02_classic/`

Colors derived from the brand logo. Arrangement emphasizes **magenta as primary + gold**, with cream/paper backgrounds and **serif typography**.

## Logo-derived palette
- Primary: `#802060` (magenta) · Accent: `#F0C020` (gold) · Dark: `#3D1633`
- Ink: `#341D33` · Muted: `#6E5567` · BG: `#FAF4EE` (cream) / `#FFFFFF`
