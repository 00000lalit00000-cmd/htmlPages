# Variant 04 — Vibrant (Bold · Polychromatic)
**Folder:** `ux/pages/variant_04_vibrant/`

Colors derived from the brand logo. Uses the **most saturated logo colors together**: vivid pink, cyan, gold on navy — playful and high-energy.

## Logo-derived palette
- Pink: `#C02080` · Cyan: `#00B0E0` · Gold: `#F0C020` · Navy: `#204060`
- Ink: `#0F172A` · BG: `#FFFFFF`

## Component design language (variant 04)
| Component | Design language |
|---|---|
| Navbar | Gradient-text brand, pill CTA, playful badge chip |
| Hero | Diagonal gradient band with blurred blobs and floating colour chips |
| Services | Bento grid — colourful gradient tiles of varied width |
| Stats / testimonial | Rotated stat chips that straighten on hover |
| Work / portfolio | Gradient-tile figures with tag chips |
| Quote form | Filled rounded fields with pink focus ring, gradient submit |
| Footer | Dark navy with gradient accents and social chips |

**Open `components.html` to see every component of this variant on one page.**
Navigation is plain `href` links between the HTML files, so every button and menu item navigates.
`../assets/site.js` drives the mobile menu, current-page highlighting and the demo form submit.

Energetic, creative, memorable — reflects the "shine like diamond" energy and stands out in local search.
