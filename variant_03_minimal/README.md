# Variant 03 — Minimal (Editorial · Neutral-led)
**Folder:** `ux/pages/variant_03_minimal/`

Colors derived from the brand logo. Arrangement is **neutral/ink-led**: deep navy ink, generous white space, with **magenta + cyan used sparingly** as accents.

## Logo-derived palette
- Ink: `#16283B` · Muted: `#6B7280` · Accent: `#802060` (magenta) / `#00B0E0` (cyan)
- BG: `#FFFFFF` (mostly empty space)

## Component design language (variant 03)
| Component | Design language |
|---|---|
| Navbar | Left brand, right small text links, no borders/boxes, minimal |
| Hero | Large left-aligned editorial headline, single accent word, almost no chrome |
| Services | Numbered single-column index (01, 02 …) divided by hairlines — no cards |
| Stats / testimonial | Inline stat line + gold-ruled blockquotes |
| Work / portfolio | Thumbnail-led rows with hairline separators |
| Quote form | Borderless underline fields, labels above |
| Footer | Single centred line, minimal |

**Open `components.html` to see every component of this variant on one page.**
Navigation is plain `href` links between the HTML files, so every button and menu item navigates.
`../assets/site.js` drives the mobile menu, current-page highlighting and the demo form submit.

## Vibe
Calm, premium, content-first — lets the portfolio and services stay the hero.
